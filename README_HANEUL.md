## ✨ О проекте

**HANEUL (하늘)** в переводе с корейского означает «небо» — символ новых возможностей, открытий и роста.

HANEUL — MVP-прототип учебной платформы, который помогает сделать первые шаги в изучении корейского языка понятными, наглядными и интересными. Проект объединяет учебные материалы, практику и инструменты отслеживания прогресса в одном пространстве.

## 🎯 Для кого создан HANEUL

| Возраст | Направление |
|:--:|---|
| **5–6 лет** | Игры, звуки, песни и первые приветствия |
| **7–9 лет** | Хангыль, слоги, слова и простые фразы |
| **10–12 лет** | Чтение, письмо и базовая грамматика |
| **13–15 лет** | Диалоги, грамматика и небольшие проекты |
| **16–18 лет** | Общение, чтение и подготовка к TOPIK по готовности |

## 🚀 Запуск проекта

### Локально

1. Скачайте или клонируйте репозиторий.
2. Откройте `index.html` в современном браузере.
3. Перейдите по разделам и попробуйте интерактивные функции.

Сборка и установка пакетов для текущей статической версии не требуются.

### Клонирование

```bash
git clone https://github.com/YOUR-USERNAME/haneul-korean-academy.git
cd haneul-korean-academy
```

Замените `YOUR-USERNAME` на имя своего GitHub-аккаунта.

## 🌐 Публикация на Vercel

1. Войдите в [Vercel](https://vercel.com/).
2. Подключите GitHub.
3. Импортируйте репозиторий `haneul-korean-academy`.
4. Оставьте Build Command пустым.
5. Если требуется Output Directory, укажите `.`.
6. Нажмите **Deploy**.

После успешной публикации Vercel предоставит публичную ссылку.

## 🔐 Важная информация

Это демонстрационный проект. Часть данных профиля и прогресса хранится локально в браузере и не синхронизируется между устройствами.

Полноценная серверная авторизация, база данных, реальные платежи и действующая система скидок пока не реализованы. Не вводите в прототип реальные пароли и конфиденциальные данные.

Мы хотим, чтобы изучение корейского начиналось не со страха перед незнакомыми буквами, а с любопытства, маленьких достижений и желания двигаться дальше.
